# Gaussian Elimination with Partial Pivoting

A production-oriented implementation of Gaussian Elimination with Partial Pivoting for solving linear systems of the form:

\[
Ax = b
\]

This module is part of the **Quant Engine** project and serves as the mathematical foundation for future numerical algorithms.

## Features
- Gaussian Elimination
- Partial Pivoting
- Input Validation
- Back Substitution
- Comprehensive Unit Tests

## Project Structure
```
gaussian.py
tests/
examples/
```

## Running the Example
```bash
python examples/gaussian_example.py
```

## Running Tests
```bash
pytest
```
